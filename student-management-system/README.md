# StudentFlow — Student Management System

A responsive student management dashboard built with **HTML, CSS, and JavaScript**. Track student grades, class performance, attendance, and individual progress in one place.

## Features

- Dashboard with student count, average grade, attendance, and support indicators
- Student directory with search, performance filters, pagination, and CSV export
- Add, view, and edit student records
- Subject grade breakdown and individual student profiles
- Top students leaderboard and performance chart
- Responsive layout for desktop, tablet, and mobile
- Saves records in browser `localStorage`
- Lime, pink, deep pink, teal, and blue accent palette

## Getting started

1. Download or clone this project.
2. Open `index.html` in your browser.
3. Add or edit records from the dashboard.

No build step is required. Chart.js, Bootstrap Icons, and Google Fonts are loaded from CDNs, so an internet connection is needed for those assets.
